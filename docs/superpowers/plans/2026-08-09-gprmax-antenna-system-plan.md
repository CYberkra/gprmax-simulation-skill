# gprMax Antenna, Port, and Receiver-System Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enforce representation boundaries between ideal field sources, electromagnetic antenna models, and calibrated hardware/system models, including feed topology, port definitions, absolute power calibration, isolation/coupling dataflow, receiver noise, averaging, ADC, and dynamic range.

**Architecture:** Keep antenna geometry/topology checks separate from system-chain checks. `scripts/audit_antenna_port.py` validates representation, discretized feed connectivity, and port evidence. `scripts/audit_receiver_chain.py` validates calibrated power identity and ordered signal/noise transformations.

**Tech Stack:** Python 3.11+, NumPy, pytest; optional small gprMax geometry/port fixtures.

## Global Constraints

- `A0 idealized source`, `A1 electromagnetic antenna`, and `A2 calibrated hardware/system` are separate claim levels.
- A point E/H receiver does not become 50-ohm dBm without an analytical or numerical calibration bridge.
- A configured isolation/noise/gain parameter counts only if a dataflow audit proves it affects the downstream signal or metric.
- Generator output, incident power, accepted power, radiated power, and EIRP are distinct identities.
- S11 naming requires a valid incident/reflected wave or impedance/reference definition.
- Receiver-chain operation ordering is explicit; correlated/static errors are not reduced by `sqrt(N)` unless physically justified.

```python
def reflection_from_impedance(zin, z0):
    zin = np.asarray(zin, np.complex128)
    z0 = float(z0)
    return (zin - z0) / (zin + z0)


def accepted_power_from_incident(incident_w, gamma):
    return np.asarray(incident_w, float) * (1.0 - np.abs(gamma) ** 2)
```
