# gprMax 仿真通用工作流与硬经验规则（完整版 v0.2）

> **状态**：设计定稿 v1.0（2026-08-30），本文件为评审稿（中文），定稿后固化为 `SKILL.md` 与 `references/`（英文）。
> **来源**：80 m 深部 SFCW 频段判决项目（gprMax 3.1.6 GPU FDTD）30+ 研究包踩坑沉淀 + 多轮设计讨论，已通用化。
> **定位**：通用 gprMax 仿真辅助 skill。**不内置任何检测/分辨/虚警判据**（那些是具体项目需求），只负责从"一个想法"到"可看的 Ascan/Bscan 结果"的全流程。
> **通用化原则**：核心规则**不硬编码任何项目特定数值**；项目值全部收敛于附录 A（case study），仅作示例与回归基准。
> **来源标注**：`[根]`=根 AGENTS.md，`[库]`=资料库 AGENTS.md，`[判据]`=判据规范 v2.1，`[汇总]`=判据 v2 结果汇总 §N，`[论文]`=刘东洋/肖建平 2021（中南大学）。

## 0. 总纲

1. **结论从声明反推，不是从模型正推**（claim-first）。动手前先明确：科学/工程问题、允许结论范围、最小可观测、单变量、介质假设、波形体制、指标、证据要求。
2. **fail-closed**：任何阻塞性缺陷（数值/物理/处理/标定/证据）必须停止升级，不允许"看起来差不多就继续"。
   ```text
   FAIL → STOP → 根因 → 修复 → 回归测试 → 重跑受影响门 → 恢复
   ```
3. **数值有效 ≠ 物理有效 ≠ 工程有效**。成功的 `.out` 只是数值有效；物理验证需要受控对比；硬件/系统声明需要标定链路。
4. **原始证据不可变**；每次处理都产生带来源的新派生工件。
5. **历史失败升格为规则必须有门槛**：根因确认 + 修复验证 + 适用范围界定，否则只作 case study。
6. **用户优先**：用户明确指定处理方式/参数时，优先按用户要求执行；推荐只是默认。

## 2. M1 初始化建模向导

**交互形态**：agent 对话引导（降低认知负担），完成后 dump 问答记录 + `simulation_contract.yaml`，用户过目确认后再调用 CLI 生成骨架。

**提问流程（Step 1-5）**：
```
Step 1 场景定位：场景类型（隧道/滑坡/考古/岩土/工程检测/其他）+ 目标埋深/距离
Step 2 目标与围岩：目标是什么（如有）+ 围岩介质（如有）——未知标"待调研"
Step 3 频段与体制：是否需要 SFCW 体制结论？频率范围（已知/由目标深度推导）
Step 4 拟真度取向：简单验证 / 标准研究 / 发表级（影响天线/不规则/网格档位）
Step 5 环境：本机 or 服务器（由用户决定；探测只提供信息）
```

**UX 特性**：
- 支持 `back` 回退到上一步修改；中间态可保存后续继续
- 每确认一步生成**几何截面示意图**（材料分布 + 目标位置 + Tx/Rx）
- 支持**参考图导入**（地质剖面图/实测雷达图拖入，agent 辅助建模）

**产出**：问答记录 dump + `simulation_contract.yaml`（进 M9 数值门校验）→ 模型包骨架（按 M8 目录规范）。

## 3. M2 调研与材料库/模板库

**调研执行**：agent 联网（文献/权威数据）。实时进度反馈（"正在查砂岩…已找到 3 篇"）。对材料库缺条目、或场景惯例未知项自动展开。

**材料库条目 schema**（YAML + 索引 JSON 存储，skill 仓库内；用户项目可 `materials_override/` 覆盖）：

```yaml
name: 砂岩（干燥）
category: rock            # rock/soil/concrete/metal/water/void/composite/other
properties:
  eps_r: 4.5 ± 0.5
  sigma_s_m: 1e-4
  model: none             # none/debye/lorentz/drude/measured_complex
  eps_inf: null; delta_eps: null; tau_s: null   # 色散参数（如有）
frequency_valid: [10, 1000]    # MHz
condition: null           # 含水率/孔隙率等条件维度（干/湿/饱和）
source:
  kind: measured | literature | assumed | sensitivity
  ref: "Knight & Nur 1987 (Stanford)"
  url: null
confidence: 4             # 1-5
notes: null
```

**关键点**：
- `condition` 维度必须（地质材料介电常数对含水率极敏感：干砂 εr=3-5 → 湿砂 20-30）
- **用户确认后才入库**；未标注来源的值只作草稿不冻结
- 调研结果**对比可视化**（柱状图/对比表，标注 最优/折中/不推荐 + 特性说明）
- **场景模板库**：**渐进积累**——skill 使用过程中在大的阶段（模型定稿/批量完成/研究收尾）自动总结更新；煤矿矿道为第一个积累条目

## 4. M3 配置轴推荐

**配置轴清单**：

| 配置轴 | 选项范围 | 推荐依据 |
|---|---|---|
| 天线模型 | 理想赫兹偶极 / 实体天线 / 无天线（平面波注入）| 场景调研 + 拟真需求 |
| SFCW 等效 | 关（宽带直出）/ 开（LTI 冲激响应法，对齐刘2021）| 是否需要 SFCW 体制结论 |
| 色散模型 | 常数 / Debye / Lorentz / Drude / 实测复介电 | 材料调研结果 + 频带范围 |
| 模型加噪 | 无 / AWGN（指定 SNR/D）/ 干扰目标体（场景杂波）| 是否需要噪声/统计分析；干扰体清单依据场景调研 |
| 目标体几何 | 规则（box/cylinder）/ 不规则 L1-L4 | 规避平整界面相干伪影 + 拟真需求 |
| 网格策略 | 由前 5 项自动推荐：dx/dy/dz、PML 层数 | cells/λ ≥10 + 时窗 + 域尺寸 |
| 数值精度 | 自动决策 fp32/fp64 | 需求动态范围 vs fp32 地板（~−90 dB）|
| 运行环境 | 本机 / 服务器（多卡）| 用户决定；探测供信息 |

**不规则建模 L1-L4 分层**：
- L1 规则体（`#box`/`#cylinder`）
- L2 规则 + 粗糙界面（高斯 σ=5/10cm，Lc=15-20cm）
- L3 非规则轮廓（掩膜 HDF5 `#geometry_objects_read`，样条/贝塞尔截面沿 x 拉伸）
- L4 逼真自然（分形粗糙 fBm + 材料渐变过渡层 + 内部异质嵌套）——可逐层叠加

**UX 特性**：依赖关系可视化（选 SFCW → 锁频点 → 网格精度 → 显存 → 环境）；每项推荐可折叠展开原因；用户逐项确认/修改。

## 5. M4 SFCW 等效链（对齐刘 2021）

**方法基准**：刘东洋/肖建平 2021《基于冲激响应原理的步进频率探地雷达信号快速正演模拟及融合》。

```
SFCW 等效（默认 LTI 冲激响应法）
  ├─ 正演：内置 impulse 单步冲激 → h[n]（一次 FDTD）
  ├─ 频点：f_n = f_0 + (n−1)Δf（用户场景决定）
  ├─ 合成：h[n] 与各频点连续波时域卷积 = 逐频点正演等效（误差 <−200 dB）
  ├─ 提取：正交混频 I/Q → 低通滤除 2f_n → 复采样 A/2·e^{jφ}
  └─ 融合：IFFT → Ascan → 拼 Bscan
  └─ 可插拔：用户可换自定义处理链（如项目冻结 A 链）
```

**已查证**：gprMax 3.1.6 内置 `impulse` 波形类型（`waveforms.py:110`），宽度恰为 1 个 FDTD 时间步的理想 δ 脉冲，可完整复刻论文方法。用法 `#waveform: impulse 1 1e9 imp` + `#hertzian_dipole: z x y z imp`。数值色散自动分析遇 impulse 会跳过（自己按式6算即可）。

**内置约束**：网格 `dx ≤ c/(10·f_max·√ε_max)`（按最高频点）；CFL `dt ≤ 1/[c·√(1/dx²+1/dy²+1/dz²)]`；时窗覆盖最远目标双程走时；发射信号斜坡防吉布斯伪影。

**与项目 A 链差异**（附录记录）：论文链无去卷积/无加窗/无参考相减；A 链用 flatpulse + 精确复采样 + Wiener 去卷积 + Blackman。

## 6. M5 环境探测

**探测内容**（只读）：GPU 型号/显存/CUDA、系统内存、磁盘剩余（仿真输出盘）、Python 版本（≥3.11？）、gprMax 是否安装及版本。

**不探测**：CPU 型号、用户名、目录结构、文件内容、进程列表、网络连接。

**输出**：环境报告 + 关键提示（如"本机无 GPU"）。**只提供信息，本机 or 服务器始终由用户决定**；探测目的是让 agent 了解本机可用资源，方便后续开展仿真。

**可选增强**：模型-环境匹配度提示（如"该模型预估需 20GB 显存，本机 24GB，匹配 100%"）防显存不够。

## 7. M6 批量仿真

```
① 定义扫描（两种入口）
   ├─ contract 内联 scan: 简单维度  target_distance: [78,79,80]
   └─ CSV 矩阵:            复杂组合（笛卡尔积 / 显式 case 列表）
② 展开 → 生成 N 个 case（独立 case_id + 参数快照 + 输入路径）
③ 自动校验（逐个 case，展开后运行前）
   - 几何：网格对齐 / 目标重叠 / 间隙 / PML 净距
   - 材料：可解析（材料库存在）
   - 数值：cells/λ ≥10 / CFL dt / 时窗覆盖最远目标
   ⛔ 校验失败 case 列 fail，不进运行队列
④ 运行编排
   - 单机：顺序 / 本机 GPU 池
   - 服务器：farm 按卡分片，断点续跑（跳过已有 .out）
   - 每 case 独立日志 + 状态机（pending/running/done/fail）
   - 实时看板：进度 / 失败 / 单独重试
⑤ 结果汇总：case→状态→输出路径 总表；失败根因分类（几何/材料/数值/超时）
⑥ 自动对比：批量跑完出对比曲线/热力图
```

**防呆核心**：第③步展开后自动校验，把"盒子中心 vs 左边缘偏移、目标重叠、PML 净距"拦在运行前。

## 8. M7 结果处理

**处理链类型**（按需求自动推荐）：
| 链 | 内容 | 用途 |
|---|---|---|
| 原始可视化 | Ascan/Bscan 直接绘制（时间-幅度）| 快速查看 |
| 标准链 | 去直达波 / 背景相减（诊断）/ SFCW 融合（对齐刘2021）| 常规 |
| 高级链 | 去卷积(Wiener) + 加窗(Blackman) + zero-padded IFFT + Hilbert 包络 | 高要求 |
| 成像 | 可选 BP/Kirchhoff（按需）| 孔径聚焦 |
| 显示增强 | 归一化 / AGC / 裁剪 | 仅显示，不参与定量 |

**原则**：
- **用户指定优先**（用户明确要求某种处理 → 直接照做）
- 显示增强与定量判据**分离**（归一化/AGC/裁剪不进定量）
- 处理链**冻结**（同一研究内不中途更换；对比性结论在同一链下）
- 处理链参数全部记录（可复现）

**输出物**：Ascan 图（时间/距离双轴）+ Bscan 图（多道拼合，处理前后对比）+ 处理链参数记录。可选：处理对比滑块、预设处理模板。

## 9. M8 文件夹管理规范

```
<study_id>/
├── README.md                    # 研究目的 / 冻结参数 / 决策记录 / 变更日志
├── simulation_contract.yaml     # 契约（向导产出）
├── manifest.json                # 运行清单：case/hash/精度/状态/校验和
├── materials/                   # 本研究材料定义（或引用全局材料库）
├── waveforms/                   # 波形文件（impulse / 自定义）
├── cases/                       # .in 输入（生成或手写）
├── scripts/                     # 生成 / 校验 / 分析脚本
├── tests/                       # pytest 几何校验
├── logs/                        # 运行日志（每 case 独立）
├── outputs/                     # 原始 .out —— 不可变，只读
├── analysis/                    # 处理链代码 + 中间产物
├── results/                     # 最终图表 / 结论 / 汇总表
└── evidence/                    # 审计报告 / 哈希 / manifest 副本
```

**命名规范**：
| 项 | 规则 | 示例 |
|---|---|---|
| 研究目录 | `序号_日期_主题_关键参数` | `01_20260830_SFCW_SLIDE_WET` |
| case_id | 大写、场景_目标_类型_道号 | `SLIDE_WET_H1_T007` |
| 目录名 | snake_case | `cases/`、`outputs/` |
| 冻结交付 | 新研究开新目录，不改旧包 | — |

**纪律**：`outputs/` 只读不可变；`results/` 是衍生结论；`evidence/` 放审计留档；`README.md` 记录每个有意变更（不得静默改参数）。

## 13. 硬经验规则（通用化）

### A. 输入文件与波形
| 规则 | 来源 |
|---|---|
| 波形表头第一行必须有波形 ID（`readline().split()` 非空）；`time` 作为时间列名可选，非必须 | `[根]` |
| 波形采样时长 × dt ≥ 仿真时窗（gprMax 短则补零、长则截断，波形不足时窗→频谱失真）| `[根]` |
| GPU 参数形态以目标 gprMax 版本 CLI 为准（3.1.6 认 `-gpu`，`--gpu` 被拒）| `[根]` |
| 不顶母带高频边缘，留 10-20 MHz 滚降余量（高频 coda 伪峰）| `[根]` |
| 波形是冻结工件：不重命名/不改写/不混用 | `[根]` |

### B. 网格与数值
| 规则 | 来源 |
|---|---|
| 频带上限处最短材料波长 cells/λ 达标（≥10，色散介质取频带中心相速度）| `[论文]`/`[库]` |
| 色散介质检查 τ/dt（>4）；明确 CFL 依据 | `[库]` |
| 关键尺寸用整单元格表达，报告"名义 vs 实现"两套数值 | `[判据]` |
| 各向异性网格（dx≠dy≠dz）允许但须论证所测观测量由哪方向单元控制 | `[库]` |
| fp32 数值地板 ~−90 dB；需求动态范围 >110 dB 必须 fp64；dtype 以 `.out` 实测为准 | `[判据]`/`[汇总]§5` |
| 域尺寸与 PML 余量保证边界相互作用在分析时窗内到不了接收机 | `[判据]` |

### C. 材料与色散
| 规则 | 来源 |
|---|---|
| 每个材料记录：模型/参数/出处/适用频段；多套参数并存时引用注明版本 | `[根]`/`[库]` |
| 不静默改材料/网格/波形/收发/精度；变更写 README 开新 case | `[库]` |
| 声明目标与围岩的对比机制；区分"工程灵敏度点"与"实测标定" | `[库]` |

### D. 几何与坐标
| 规则 | 来源 |
|---|---|

## 附 A. 案例值（case study，非通用规则）

> 仅作示例与回归基准；推广到其他场景需重标定。

- 介质：煤（两套 Debye 并存，引用注明）——EC-35：ε_inf=2.746、Δε=0.255、τ=3.114e-10 s、σ=2.28e-4 S/m；NEWCOAL(Zhang2020)：ε_inf=2.811、Δε=0.182、τ=3.397e-10 s、σ=1.45e-4 S/m
- 目标：WET 含水破碎带 ε_r=5.17、σ=0.05 S/m（工程灵敏度点）
- 天线：z 极化赫兹偶极，Tx/Rx 基线 0.5 m
- 链路：37 dBm/频点、G_rx=1.5、NF=6 dB、df=0.5 MHz、噪声底 ≈−111 dBm/频点
- 网格：0.04×0.05×0.05 m（常规）/ 0.04³（HIRES）/ 0.04×0.0625×0.0625（GAP1M 基准）
- 判据：P_D（Wilson 下限 ≥0.90）、P_FA（设计 0.01、上限 ≤0.02、判稳 ≤0.017）、P_R（3dB 谷深）、链路余量 ≥6 dB；精度门 D≤110 dB fp32、>110 dB fp64
- 当前基准结论（2026-08）：GAP1M 冻结 A 链首过 30–213 / 35–200 / 40–188 / 45–177 MHz；0.96 m 厚破碎带面积阈值 A≈0.618 m²（仅限该形状族/深度/链路）
- 口径：新判据 v2.1 从 Tx 相位中心起算，煤面 R=0.48 m
